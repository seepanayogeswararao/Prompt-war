# NOVA SMART — Hackathon Prototype

## Run
1. Install Node.js 18+.
2. Open this folder in VS Code/terminal.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown by Vite.

## Demo
Use the top-right role switcher:
- Customer: search `Milk`, compare availability confidence, add to cart, run Pre-order Risk Check, place order.
- Store: update Milk inventory and watch stock risk/confidence change.
- Admin: inspect the Business Command Center and move the Business Impact Simulator slider.

This is a self-contained prototype using deterministic demo data. It does not require paid APIs, Supabase, or API keys.
